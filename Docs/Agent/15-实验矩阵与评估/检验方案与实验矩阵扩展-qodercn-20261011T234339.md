## 2. 检验方法论

### 2.1 五层检验栈

| 层 | 内容 | 手段 | 适用系统 |
|---|---|---|---|
| L0 静态对账 | 导出符号存在性、文档声明与实现的差、零调用者扫描 | grep / find / node 探针 | 全部 9 个（尤其 7、9 两个纯文档面） |
| L1 契约单测 | 判定点函数级断言（守卫返回码、状态枚举、排序单调性） | `Tests/**` 单文件跑 | 1 / 2 / 3 / 4 / 8 |
| L2 组件集成 | 跨模块链路（工具→journal、事件→记忆、招募→回传） | `Tests/LoopControl`、`Tests/A2A` | 1 / 4 / 6 / 8 |
| L3 真实模型端到端 | 真实 API Key，≥3 轮真实 Agent 调用 | `Tests/E2E`（需改造 key 门禁） | 5 / 9 |
| L4 对抗注入 | 语料驱动攻击（种子 `Benchmarks/datasets/adversarialSeeds.json`） | `Tests/Experiments/adversarial` | 1 / 2 / 3 / 4 / 6 / 8 |
| L5 混沌与恢复 | 崩溃 / 满盘 / 时钟回拨 / 分区 + checkpoint 恢复 | `Tests/Durable/faultInjection.spec.ts` | 1 / 4 / 5 |

### 2.2 四条反假绿铁律

1. **缺 Key 记 FAIL 或 NOT-RUN，不记 SKIP-pass**。13 个"缺 key 即 return"用例应先重登记为 `declared-only`，并输出 NOT-RUN 计入落地率分母。
2. **锚点升级为断言级**：`anchor` 必须能在锚定文件内 grep 到 `it()` 标题命中 cell id 或 oracle 关键词；新面一律用 `// @matrix:<ID>` 标签锚，禁用纯文件锚。
3. **每个 oracle 必须可证伪**：同 cell 附反例输入，证明判据真会拒绝错误行为（例：`SEC-NET` 若只断 `isNetworkAllowed('evil.example.com')===false` 而不测 `webSearch.ts:80` 的实际外联，即为假覆盖）。
4. **缺口用 `gap` / `declared-only` 标注，不写伪断言**（沿用项目 §1.5 既有约定）。第 7（分裂）、第 9（多模态）两个无实现面只登记声明与前置能力清单。

### 2.3 实验执行前置阻断（P0）

- **REV-429 仍未修**（2026-10-11 复核成立）：`Tests/Infra/secretsStore.spec.ts:43-51` 仍对硬编码真实路径 `Data/.secrets/providers.json.enc` 执行 `copyFileSync → rmSync`，靠 `afterEach` 还原本机真实凭据；根 `vitest.config.ts` 无 `fileParallelism: false`。用例超时被强杀 / 进程崩溃 / 并发跑都会留下 `.testbak` 并使应用读不到任何密钥。
- 因此本文所有实验的执行标准为：**单文件跑 + `CIVITAS_DATA_ROOT` 指向临时目录**；禁止在全量 `npm test` / `--coverage` 下取证；不读写 `Data/`（含 `_test*` 测试库）与 `Logs/`。参照同目录 `Tests/Infra/userConfigWriter.spec.ts` 的 `mkdtempSync` + env 注入写法。
- 评测卫生：`longTermMemory.ts:searchMemories` 有写副作用（`accessCount` / `lastAccessedAt`，≥5 触发 `MEMORY_SELF_REINFORCING`），检索类实验必须在副本上进行或关闭计数。
