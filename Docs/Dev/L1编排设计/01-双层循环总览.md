## 0. 两个前提（决定了后面所有图的形状）

1. **组装器本质上是工具** —— 外层不是"特殊代码路径"，而是**外层 LLM 调一个工具**。
   这样"组装"可审计、可审批、可拒绝，与 `registerTool` 拒注同形。
2. **分裂必须在内层可达** —— 若分裂只在外层（组装层）可用，那么一旦进入内层 ReAct 执行，
   agent 就再也无法分裂。**分裂是任务执行中的判断，不是组装期的判断**，所以它必须在内层工具表里。

## 1. 总览：单 L1 agent 的双层循环

```mermaid
flowchart TD
  IN([任务输入]) --> OUT

  subgraph L1["单 L1 Agent"]
    subgraph OUT["外层循环：选择 / 组装"]
      O1["外层 LLM：选下一个组件"] --> O2{"组装需要变更？"}
      O2 -- 是 --> O3["调组装器工具<br/>OrchestratorCompose(变更)"]
      O3 --> O4{"检查树：本次组装是否闭环"}
      O4 -- 不通过 --> O1
      O4 -- 通过 --> O5["落盘组装体 + 审计留痕"]
      O5 --> O6["选定组件"]
      O2 -- 否 --> O6
    end

    subgraph INN["内层循环：ReAct（十步）"]
      I1["①InputReceived ②PreSupervision ③Middleware"] --> I2["④ContextAssembly ⑤LazySupervision"]
      I2 --> I3["⑥ModelCall ⑦OutputParse"]
      I3 --> I4["⑧ToolExecute"]
      I4 --> I5["⑨PostSupervision ⑩IterationDecision"]
      I5 -- 继续 --> I1
      I5 -- 退出 --> I6(["组件返回"])
    end

    O6 --> I1
    I6 --> O1
  end

  O1 -- 外层判定：已达成 Goal --> DONE([任务结束])
```

**读法**：外层决定"跑哪个组件"，内层负责"把它跑完"。`I6 → O1` 是内层回到外层的唯一出口。
