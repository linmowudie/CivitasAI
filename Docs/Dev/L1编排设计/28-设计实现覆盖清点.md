   版本一律取自框架真源；提交走真实提交器的"再校验 + 摘要 + 落盘 + 审计"）

2. **组合层当时共用父输入**：`Patterns/combinators.ts` 与 `createWorkflow` 把父 `ReactInput`
   （含 grants/observation）原样透传给子件 ⇒ R3/R4「事件带自身 scope」在真实嵌套路径上无从生效。
