```bash

**外加（这是本页的重点）**：每步必须新增**至少一条负向测试**，形态照抄本仓已跑通的两个先例：

```
registerTool(非法) → 断言 ok === false          ← "非法即拒"的形态（已跑通）

**禁止**用"静态匹配"充当负向验证：

| 不算通过 | 因为 |
|---|---|
| 断言源码里含 `if (violations.length)` | 只证明**写了**检查，不证明**检查会拒** |
| 断言注释/文档里提到该判据 | 本仓已有"审计把注释当代码"的教训 |
| 断言函数存在 | 存在 ≠ 被调用 ≠ 生效 |

## 6. 建议的第一枪

**S0**（修两个既有缺陷）—— 理由：① 它**不依赖任何新组件**；② 它是多个组件的**前置**；③ 它能立刻给出一条**真实调用**的负向测试，

```
① 挂一个 afterAgent 插件 → 断言 runIteration 后它被调用（当前必然失败，修后才通过）

```

**这两条现在就能跑，且现在应该是"红的"** —— 先让它们红，再让它们绿。
