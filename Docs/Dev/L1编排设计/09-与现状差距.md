## 7. 与现状的差距（核实过的事实）

| 设计所需 | 现状 | 差距 |
|---|---|---|
| 内层 ReAct 作为**可嵌套原语** | `Src/Core/Loop/runIteration.ts`（十步，住在 Core，视作全局唯一循环） | 需可实例化、可重入 |
| 外层循环 | **不存在** | 需新建（L1 独有） |
| 组装器（工具） | **不存在** | 需新建（`orchestrator.compose`） |
| 外层状态落盘 | `afterAgent` **从未被派发**，`checkpointWriter` 是死代码 | **真缺陷**：外层状态无处持久化 |
| 内层决策点 | ⑩ IterationDecision（内层） | 外层决策点是**另一个新位置**，不在此 |
| 分裂（同级召唤） | `agent.recruit`（招募**下级**子代理） | **不是**分裂；需 `agent.split`（同级 + 冲突域 + 每次 1 个） |
| L2 单层 | 由构造决定（只有 Director 做复杂度评估） | 需显式化：L2 没有外层 |
