## 3. 分裂：完整闭环（发起者与被召唤者都是 L1、**同级/兄弟**，各跑双层循环）

```mermaid
flowchart TD
  A["L1 判断：任务过于艰难<br/>即使召唤子代理也无法解决"] --> B["按**冲突域**拆分任务<br/>确保工作内容高度隔离"]
  B --> C["调 AgentSplit<br/>召唤 **1 个同级别 L1** agent"]
  C --> D["把拆分后的一份任务交给它"]
  D --> E["发起者与其**兄弟**（同级 L1）各自跑自己的双层循环"]
  E --> F{"共享上下文拉取相关文件时<br/>发现某 agent 工作内容高度相关？"}
  F -- 否 --> E
  F -- 是 --> G["调 AgentMerge：向监管请求合并"]
  G --> H{"监管批准？"}
  H -- 批准·完全合并 --> I["两 agent 合一"]
  H -- 批准·归属转换 --> J["相关子代理转归另一方"]
  I --> K["**生成子代理继续工作**"]
  J --> K
  K --> L["（回到单 L1 双层循环）"]
```

**关键**：`C` 这一步在内层可达（图 2），否则 `A` 这个判断发生在执行过程中时无处执行。
