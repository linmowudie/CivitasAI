## 0. 使用说明

1. **如何检索**：全表按 15 个主题节组织，每节一张表。检索术语用编辑器搜索中文词或「英文/标识符」列；
   缩写先查 §15「缩写与编号索引」，其中给出每个缩写指向的定义所在小节与权威出处。
2. **如何判权威**：每条词条的「权威出处」满足以下优先级——**代码存在时以代码为准**（给出 `路径:行号`）；
   仅存在于文档的概念标注 `（仅文档）` 并在出处给出文档章节。「别名」列收录项目中出现过的其他叫法，
   已废弃的标 `(旧)`；「关联」列可串起概念网，发现矛盾时以「权威出处」指向处为准。
3. **发现冲突时**：当代码与文档口径不一致，本表在词条内以「**代码说 X，文档说 Y**」两侧记录，不做设计裁决
   （裁决不在本任务范围）。冲突汇总见 §16。
4. **列定义**（每节固定 7 列）：
   | 列 | 说明 |
   |---|---|
   | 术语 | 中文优先 |
   | 英文/标识符 | 代码里的真实标识符，与代码逐字符一致 |
   | 别名 | 项目中其他叫法，`·` 分隔；废弃的标 `(旧)` |
   | 定义 | 一句话，≤60 字 |
   | 权威出处 | `路径:行号` 或 `Docs/... §x`；（仅文档）= 无代码承载 |
   | 所属层 | `Interface`/`Core`/`Services`/`Tools`/`Infra`/`Client`/`Server`/`Docs`/`跨层` |
   | 关联 | 相关术语，`·` 分隔 |
5. **词条计数**：15 个主题节主表共 **479** 条（分布：§1=15、§2=17、§3=68、§4=39、§5=50、§6=32、§7=35、§8=22、§9=23、§10=22、§11=28、§12=31、§13=14、§14=52、§15=31）；另 §16 冲突清单 24 条、缺口清单 9 条，全文合计 **512** 条。
