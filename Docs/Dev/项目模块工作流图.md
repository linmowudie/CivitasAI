## 2. 主循环模块（`Core/Loop/runIteration.ts`）

```mermaid
flowchart TB
  Start(["任务进入（L1 入口）"]) --> Pre
  subgraph LOOP["每一轮迭代（iteration）"]
    direction TB
    Pre["① 输入接收 / ② 前置监管"] --> MW["③ 中间件链<br/>LoopControl/middleware"]
    MW --> Ctx["④ 上下文装配<br/>systemPrompt 三区 + ContextStore 追加"]

    Post --> Decide{"⑩ 迭代决策"}

    Decide -->|"终止"| End(["退出循环 → 汇总"])
    Snap --> Pre
  end
  Exec -.->|"DANGEROUS + 不可逆"| Gate["审批门（阻塞）"]
  Gate --> Exec

  classDef gov fill:#2d1b4e,stroke:#8b5cf6,color:#fff
  class Gate gov
```

![02-loop](diagrams/02-loop.png)

**关键不变量（有证据）**：系统提示**三区分离**（静态段冻结 + 会话段 + 回合段），工具数组**确定性排序** → 前缀稳定度实测 **99.9%**（旧构造 88.9%）；每轮末尾写迭代快照 `iterationCheckpoint`（修复前 `checkpointStore` 无运行期调用方）。

**省略说明**：token 预算/成本闸、Loop 级 stopRules 的具体规则表、压缩（compact）触发细节。

## 4. 审批与治理门模块（`toolSafetyGate` → `approvalGate`）

```mermaid
flowchart TB
  Call["工具调用（DANGEROUS + IRREVERSIBLE）"] --> Pool
  Pool["按**请求方层级**构造决策池<br/>L2：用户/L1/L0 任两方；L1 自身：用户+L0"] --> Ensure["按需创建/扩容<br/>ensureAgentsForRoles"]
  Ensure --> Create["createApproval（法定人数 2）"]
  Create --> Wait["阻塞等待裁决"]
  Wait --> Decide["decideApproval<br/>① 角色须在决策池内 ② 不同角色须不同身份（匹配）③ 系统只能拒"]
  Decide -->|"通过"| Exec["放行执行"]
  Decide -->|"拒绝 / 超时"| Deny["默认拒绝（fail-closed）"]
  Decide --> Trail
  Exec --> Trail["治理留痕<br/>governance:action_recorded"]
  Deny --> Trail
  Trail --> Ledger[("governance_records 台账<br/>属主隔离 + 重启回灌")]
  Trail --> Panel["客户端「⚖治理」面板（实时）"]

  Bind["身份绑定：user → 活动账号/服务端令牌验真；Agent → 真实注册 Agent（agent-xxx 严格）"] -.-> Decide

  classDef gov fill:#2d1b4e,stroke:#8b5cf6,color:#fff
  class Pool,Decide,Trail,Ledger gov
```

![04-approval-gate](diagrams/04-approval-gate.png)

**关键不变量**：请求方角色**永不入池**（配置也改不掉）；**同一人换角色名不再满足多角色**（Kuhn 二分匹配）；`decidedBy` **不再直接采信**（自报身份作废 + 留痕 `approval.identity_mismatch`）；人类代理治理角色时**显式留痕** `approval.human_proxy`。

**省略说明**：自动审批白名单（`forceApprove`）、审批队列落库字段、客户端"单操作者模式"的多角色提交循环。

**职能部门边界（用户裁定，不可混淆）**：

**省略说明**：审判的具体裁决算法（Phase 0-2 规则裁决）、律师函挂起的时间参数、动态扩缩阈值细节。
