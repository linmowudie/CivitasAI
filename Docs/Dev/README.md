## 跨文档共性问题（按影响排序）

1. **"✅ 已实现"标注漂移**：孤岛模块（实现但无调用方，如 TokenEconomy 计量面、5 表零写入）、名义存在实则空转（afterAgent 钩子、进度追踪链、checkpoint 链路）。约半数差异属【文档过时】，根因是 9-22 校准后的修复提交（493b005、10 月初登录/同步/fail-closed 改造等）未回写文档。
2. **审批与安全红线弱化**（Agent/06、Agent/11、Agent/01 交叉证实）：autoApprove 白名单 + 自报 decidedBy 可使 CRITICAL 审批形同虚设，违反"禁止默认通过"红线；设备策略可被密码登录绕过。
3. **WS→Electron IPC 迁移未同步**：Agent/07、Agent/08、Client/01、Client/02、Agent/16 大面积条目失效；ipc 通道与 REST 新端点普遍未登记（契约盲区）。
4. **事件契约三处漂移**：注册表 vs 代码枚举、前端镜像 vs 后端发布（订阅不存在事件 / 发布未登记事件）、payload/data 字段名。
5. **幂等/fail-closed 副作用**：全 args 哈希幂等键叠加唯一约束，把"同工具同参重试"也拒了——是修复引入的新行为，两份文档均未记载，需裁定。
6. **CI/工程实据过期**：Server/02、Server/03、Agent/13 显示指南与仓库实态脱节（无 Dockerfile、build 语义、CI 必红项）。
