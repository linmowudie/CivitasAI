# 应用图标

请在此目录放置应用图标文件：

## 必需文件

1. **icon.ico** (256x256, Windows 图标)
   - 用于 Windows 安装包 и executable 图标
   - 建议使用 256x256 像素的 ICO 格式

2. **icon.png** (512x512, 通用图标)
   - 用于 Linux 和其他平台
   - PNG 格式，透明背景

## 可选文件

- **icon.icns** (macOS 图标)
  - 仅在构建 macOS 版本时需要
  
## 图标设计建议

- Civitas-AI 主题：城邦、智能体、社会协作
- 建议使用简洁的图形标识
- 避免过多细节（小尺寸下需清晰可辨）

## 临时方案

如果暂时没有图标，可以：
1. 使用任意 256x256 的 PNG/ICO 文件作为占位
2. 或从网上下载免费图标
3. 构建时 electron-builder 会使用默认图标
